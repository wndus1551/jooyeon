# content.yaml 형식

## 최상위 키

| 키 | 필수 | 설명 |
|---|---|---|
| `factory` | ○ | `data/factories.yaml` 의 공장 이름 (예: 포항공장) |
| `line` | △ | 그 공장의 라인 이름 — Pipe Size 표를 여기서 가져옴. `pipe_size` 를 직접 쓰면 생략 가능 |
| `title` | ○ | 품명. 표지·머리말·1항에 들어감 |
| `cover_title` | | 표지·머리말용 짧은 제목 (40자 넘을 때) |
| `due` | ○ | 납기. 예: `26년 3월/말` — 뒤에 "(납기는 추후 변경 가능)" 자동 추가 |
| `due_label` | | 기본 `제작 설치 및 시운전 납기`. 납품만 하는 건이면 `제작 및 납품 납기` |
| `location` | | 설치 장소. 쓰면 "3. 설치 장소" 항이 생기고 뒤 번호가 하나씩 밀림 |
| `author` | | 작성자 덮어쓰기 `{team, name, rank, tel}` |
| `pipe_size` | | `{외 경: [Min, Max, 비고], 두 께: [...], 길 이: [...]}` — 라인 기본값 대신 사용 |
| `spec_extra` | | 제품사양 2) 이후 항목 목록 `[{title, blocks}]` |
| `scope` | | 공급 범위 구분 표 `[[항목, 세아제강, 수주처, 비고], ...]` — 생략 시 기본 9행 |
| `supply_list` | ○ | 공급 List `[[세부 내용, 수량, 비고], ...]` (No. 는 자동) |
| `detail_note` | | "공급 설비별 세부 사양" 뒤 괄호 문구 |
| `details` | ○ | 세부 사양 소항목 목록 `[{title, blocks}]` → `N-1`, `N-2` … 자동 번호 |
| `safety_permits` | | 기본 `true` — 세부 사양 끝에 "안전관련 인허가 서류" 소항목 추가 |
| `install` | | 설치 공사 및 시운전 소항목 `[{title, blocks}]` — 생략 시 기본값 |
| `install_title` | | 기본 `설치 공사 및 시운전`. 납품만 하면 `납품 및 설치 협조` 등 |
| `misc` / `misc_extra` | | 기타사항 전체 교체 / 기본값 뒤에 추가 (문자열 목록, `N-k.` 번호 자동) |
| `docs` / `docs_extra` | | 문서 전체 교체 / 추가 |

장 순서 (자동 번호): 품명 → 납기 → (설치 장소) → 제품사양 → 설치환경 → 공급 범위 → 공급 설비별 세부 사양 → 설치 공사 및 시운전 → 기타사항 → 문서 → Warranty → Common List

## 장 번호 참조 `{sec:키}`

본문에 장 번호를 직접 쓰지 않는다. `{sec:키}` 가 빌드 때 실제 번호로 바뀐다.

| 키 | 장 |
|---|---|
| `spec` | 제품사양 |
| `env` | 설치환경 |
| `scope` | 공급 범위 |
| `detail` | 공급 설비별 세부 사양 |
| `install` | 설치 공사 및 시운전 |
| `misc` | 기타사항 |
| `docs` | 문서 |
| `warranty` | Warranty |
| `common` | Common List |

예: `"{sec:common}항 Common List의 PLC(LS XGT Series)"` → "11항 Common List의 …",
`"({sec:misc}-8항)"` → "(8-8항)", `"{sec:detail}-1항 4)"` → "6-1항 4)"

## blocks (본문 줄 목록)

각 줄은 맨 앞 기호로 모양이 정해진다.

| 쓰는 법 | 모양 | 용도 |
|---|---|---|
| `"# 개요 및 목적"` | **1) 개요 및 목적** (굵게, 번호 자동) | 소제목 |
| `"## 레시피별 압력 자동 변경"` | **3-1 레시피별 …** (번호 자동) | 소소제목 |
| `"- 문장"` | - 문장 | 기본 요구사항 |
| `": 문장"` | 　: 문장 (한 단 들여씀) | 바로 위 항목의 세부 |
| `"→ 문장"` | 　→ 문장 | 결과·추가 조치 |
| `"※ 문장"` / `"* 문장"` | ※ 문장 | 주의·비고 |
| `"1) 문장"` | 1) 문장 (매달린 들여쓰기, 굵게 아님) | 번호 매긴 요구사항 (JCOE 유형) |
| `"① 문장"` | ① 문장 | 하위 번호 |
| `"-. 문장"` | -. 문장 | Warranty 류 |
| 그 밖 | 일반 문단 | |
| `""` | 빈 줄 | |

`#` / `##` 뒤에 번호를 직접 쓰면(`# 3) 기능 사양`) 그대로 둔다.

글자 꾸미기: `**굵게**`, `[[확인 필요 내용]]`(노란 형광 + 목록 출력), `{{red}}빨간 글씨{{/red}}`, 줄바꿈 `\n`.

### 표

```yaml
- table:
    header: [구 분, 구성품, 역 할]
    widths: [18, 43, 39]          # 비율 (생략 시 균등)
    align: [c, l, l]              # c/l/r (생략 시 첫 열만 가운데)
    rows:
      - [하부레버 압력, "I/O Link 릴리프 밸브 (하부레버용) 1EA", 레버 ON/OFF 시 램프 압력 제어]
      - [^, 추가 구성품, 역할]      # ^ = 위 칸과 세로 병합
```

### 그림

```yaml
- {image: img/현장사진.png, width_cm: 12, caption: 유압유니트 실물 참고사진}
```
경로는 content.yaml 기준 상대경로.

## ⚠ YAML 주의

- **`[ ]` 목록 안에서 쉼표는 칸 구분자다.** 셀 내용에 쉼표가 있으면 반드시 따옴표로 감싼다.
  `["방향전환밸브 (솔레노이드밸브, 4/3-way)", 4EA, "실린더당 1EA, 동일 모델"]`
  — 빠뜨리면 스크립트가 "따옴표로 감싸세요" 경고와 함께 종료코드 2를 낸다.
- `:` 이나 `#` 으로 시작하는 줄, `- ` 로 시작하는 문장, `[` `{` `*` `→` 가 들어간 문장은 **항상 큰따옴표로** 감싼다.
  가장 안전한 규칙: blocks 의 모든 줄을 큰따옴표로 감싼다.
- 문자열 안의 큰따옴표(인치 ")는 `”` 를 쓴다.
