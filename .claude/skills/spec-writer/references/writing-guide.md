# 시방서 문체·구성 가이드

PM22 업세트 내면비드커터(26.10.21), JCOE 12M 태그웰더 SEAM부 정렬(26.09.03), A동창고 V포켓 스트로크 확장(26.07) 시방서에서 뽑은 규칙.

## 1. 문체

- 요구사항은 **"~할 것"** 으로 끝낸다. 사실 서술은 "~함", "~임", 금지는 "~적용 불가", "~금함".
  - O `압력계는 글리세린 충진형 등 진동 환경에 적합한 사양으로 할 것`
  - X `압력계는 글리세린 충진형을 사용하는 것이 좋습니다`
- 주체는 **당사**(세아제강) / **수주처**(또는 수주자)로 쓴다. "업체", "저희" 쓰지 않음.
- 한 줄에 요구 하나. 이유가 필요하면 앞에 붙인다: `기존 유압원 작동압력(24.5 MPa)이 실린더 정격압력(14 MPa)을 초과하므로, … 감압회로 구조로 제작할 것`
- 수치는 단위·기준을 함께: `승강 속도 약 600mm/min(실린더당 약 7.5L/min, 풀스트로크 기준 약 6초)`, `파괴압 기준 4배 이상 안전율`
- 아직 못 정한 것은 정식 문구로 남긴다:
  `(협의 후 확정)`, `(상세 Spec 협의 必)`, `(설치 위치 담당자 협의 必)`, `초기값은 시운전 시 확정`, `당사 제공`
  — 이건 수주처에 보내는 문구. 반면 **작성자가 확인해야 할 빈칸**은 `[[확인 필요: …]]` 로 쓴다(최종본 전에 지워야 함).
- 선택 사양은 `(선택)` 또는 `(협의 후 적용)` 을 붙이고, 적용 시 조건을 쓴다.
- 영문 용어는 현장에서 쓰는 대로: Fail-safe, Flushing, Creep Down, Meter-out, Pilot Ratio, Testing Report, Shop-Test.

## 2. 공급 설비별 세부 사양 — 두 가지 유형

### 유형 A : 기능 중심 (제어·통신·자동화 개조) — `examples/pm22.yaml`
소항목 하나(`N-1 <설비명> <시스템명> (<핵심 기술> 적용)`) 안에 `#` 소제목으로:
1. 개요 및 목적 — 구현할 기능 목록 (`- … 구현할 것` + `:` 세부 + `→` 부가 기능)
2. 시스템 구성 — 표 [구 분 | 구성품 | 역 할] + 신호 흐름(`A → B → C`) + 제어 경로 원칙
3. 기능 사양 — `##` 기능별 (설정/자동 변경, 동작 로직, 이상 시 동작(Fail-safe), HMI 표시·조작)
4. 구성/선정 사양 — 부품 선정 조건, **승인용 제출 자료**, 포트·I/O 배정표, Common List 제조사 기준
5. 제작 및 정비 요건 — 판넬/박스 제작, 라벨·접지·보호등급, 정비 편의, 배선 공사 분담
6. 안전 기능 분리 — 기존 하드와이어 안전회로·기계식 보호장치 유지
7. 시운전 및 검수 시험 항목 — 표 [시험 항목 | 시험 내용 | 확인 사항]
8. 제출 문서

### 유형 B : 부품 중심 (유압·기계 신설/교체) — `examples/jcoe12m.yaml`
소항목을 부품·주제별로 나누고(`N-1`, `N-2` …), 각 소항목 안은 `1) 2) 3)` 번호 문장:
1. 회로(시스템) 기본 구성 — 흐름 `[A] → [B] → [C]`, 제어 단위, 독립성, 편하중 등 거동
2. 핵심 부품별 소항목 — 제목에 수량 표기 `— 실린더당 1EA (총 4EA)`; 형식, 세팅값 범위, 정격, 동일 모델 통일, 정전·비상정지 시 거동
3. 배관 사양 — 구간별 설계압력, 안전율, 연결 방식, 클램프
4. 성능 요구 (동조·속도 등) — 허용 기준과 조정 방법, 세팅값 기록·고정
5. 계측 및 모니터링
6. 참고사진 — 현장 사진·레이아웃 (사용자가 준 그림이 있을 때)

## 3. 빠뜨리기 쉬운 항목 체크리스트

세부 사양을 다 쓴 뒤 아래를 하나씩 확인한다.

- [ ] 기존 설비와의 연결 지점·분기·간섭 (기존 회로·프로그램에 영향 없도록, 기존 설비 정지 일정 협의)
- [ ] 정격 초과 방지 / 이중 안전 (릴리프·감압·상하한 제한)
- [ ] 통신 단절·정전·비상정지 시 최종 상태 (최고압·낙하·폭주 금지)
- [ ] 동일 모델 통일, 예비품/교체 시 설정 복원
- [ ] 수주처가 **승인 전에 제출**할 자료 (데이터시트, 회로도, 사양서)
- [ ] 당사 사급품·당사 시공 범위 (공급 범위 표 비고와 일치하는지)
- [ ] 시운전 확인 항목과 합격 기준 (수치가 있으면 수치로)
- [ ] 세팅값 기록표 제출
- [ ] 공급 List 수량 = 세부 사양 본문 수량 (예: 본문 "4EA" ↔ List "4EA")
- [ ] 문서 장에 이 건 고유의 제출 문서가 들어갔는지 (`docs_extra`)

## 4. 공급 범위 표 작성 요령

- 기본 9행: 생산 제품 및 사양 확정(당사) / 현장 체크 및 구성도 작성(수주처) / 구성도 승인(당사) / 제작(수주처) / 검수(당사) / 납품 및 운송(수주처) / 시스템 설치(수주처) / 시운전(△, O) / 문제점 보완(△, O)
- △ = 당사 지원. 설계 도면이 필요한 건은 "도면 설계 / 도면 승인" 으로 바꾼다.
- 당사가 하는 공사(전기 배선, 취외·설치 인원 지원)는 해당 행 비고에 `별도 공사 진행`, `당사 인원 지원` 처럼 적는다.
- 납품만 하는 건(V포켓 유형): "설치"는 당사, 수주처는 "설치 입회·기술 지원", 7장 제목을 `납품 및 설치 협조` 로 (`install_title`).

## 5. 공급 List

- 세부 내용 = 품목명 + 괄호 안 구분/용도: `감압밸브 (압력보상형)`, `I/O Link 릴리프 밸브 (하부레버용)`
- 수량: `1EA`, `4EA`, `1식`, `5EA 이상`
- 비고: 세팅값·적용 위치·참조 항(`{sec:detail}항 세부 사양 참조`)
- 마지막에 문서(도면·매뉴얼 일체) 1식, 필요 시 안전관련 인허가 서류 일체 1식
