# SeAH RUN — 세아제강 퀴즈 러닝 게임

강철 로봇이 공장 단지를 달리며 장애물을 피하고, 중간중간 나오는 **세아제강 퀴즈 10문제**를 푸는 HTML 게임입니다.
`index.html` 파일 하나로 동작합니다(웹폰트만 인터넷에서 불러옴).

## 조작
| 상황 | 키 |
|---|---|
| 달리기 | `↑` / `Space` 점프 (길게 누르면 더 높이), `↓` 슬라이드 · 공중에서 빠른 착지 |
| 퀴즈 | 방향키로 고르고 `Space`/`Enter` 선택, 숫자 `1~4`, 마우스 클릭 |
| 기타 | `P`/`Esc` 일시정지, `M` 소리 켜기/끄기 · 모바일은 화면 아래 버튼 |

## 규칙
- 목숨 3개(가슴의 빨간 셰브론). 장애물에 부딪히면 1개 감소, 잠깐 무적.
- 쇠파이프 더미·라바콘은 점프, 매달린 H빔은 슬라이드로 통과.
- 퀴즈 게이트에 닿으면 문제 출제. 정답이면 +500점, 부스터 발동.
- **문제 순서와 보기 순서는 매 판 랜덤.**
- 점수 = 달린 거리(m) + 정답×500 + 완주 보너스 1000 + 남은 목숨×300
